# IPTV Brasil 2026 - Canais, Filmes e Séries

Fork com as listas já **divididas e organizadas** para importar só o que você quer (só canais BR, só US, só filmes...), cada arquivo com **menos de 30 MB** para funcionar no [Saimo TV](https://github.com/gabrielsaimo/Saimo-TV/releases/latest/download/SaimoTV-TVBOX.apk).

## ⚡ Como importar no Saimo TV (jeito mais fácil)

1. Escolha a lista na tabela abaixo.
2. Copie o **link** da coluna da direita (clique com o botão direito no link → *Copiar endereço do link*).
3. No Saimo TV, adicione uma lista por **URL** e cole o link.
4. Repita para cada lista que quiser. Listas com mais de uma parte (parte 1, parte 2...) são adicionadas uma por vez.

> Use sempre o link `raw.githubusercontent.com` (os links abaixo já são). Links da página do GitHub (`github.com/.../blob/...`) dão o erro "isso não parece uma lista .m3u".
> Quer testar rápido? Comece por `ao-vivo/BR-abertos`.

Tudo está na pasta [`listas/`](listas), separado por tipo e país. Os arquivos originais continuam na raiz, mas são grandes demais para o Saimo TV.
